# Company Prep Feature — Plan & Implementation

> **Status**: Backend + frontend wired. Pending: run migration in Supabase, run seed script.
> **Last Updated**: 2026-04-30

---

## Overview

Company Prep is a placement preparation roadmap feature. Students select a target company and follow a sequential round-by-round roadmap to prepare for campus/hire placement processes. Each company has multiple rounds (aptitude, coding, interviews) and progress is tracked as rounds are completed.

## Implemented Components

### ✅ Frontend

- **`frontend/src/pages/CompanyPrepPage.jsx`**
  - Grid of company cards showing: name, tier, difficulty, hiring numbers, tagline, round count
  - Progress bar per company (localStorage-based)
  - Status badges: "Not started", "In progress", "Mastered"
  - CTA: "Start preparing" / "Continue prep"

- **`frontend/src/pages/CompanyPrepDetailPage.jsx`**
  - Company hero section with logo, color, tagline, badges
  - Round-by-round vertical roadmap with:
    - Step circles (numbered / locked / completed)
    - Round card: title, duration, summary, topic pills
    - "Mark this round complete" button (unlocks next)
    - Progress bar
    - Reset progress option
    - Trophy animation when all rounds done

- **`frontend/src/lib/companyPrepData.js`**
  - Static data for all 8 companies
  - Each company: slug, name, initials, color, tier, difficulty, hiring, tagline, rounds[]
  - Each round: title, duration, summary, topics[]
  - `findCompany(slug)` helper function

### ✅ Database Migration

- **`scripts/migrations/2026_04_30_company_prep.sql`**
  - `company_rounds` — stores company + round definitions
  - `company_round_progress` — per-student per-round unlock state
  - `practice_sessions` — practice activity tracking
  - `practice_responses` — per-question practice responses
  - `company_round_attempts` — multiple timed test attempts per round
  - Adds `topic` column to `question_bank`
  - RLS policies for authenticated access
  - Indexes on slug, student_id, company_name

## API Endpoints (Implemented)

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/company-prep/companies` | List all companies with rounds |
| GET | `/api/company-prep/progress` | All-companies progress map for the calling student |
| GET | `/api/company-prep/:slug` | Get company detail with rounds |
| GET | `/api/company-prep/:slug/progress` | Get student's progress for a company |
| POST | `/api/company-prep/:slug/progress` | Mark a round complete (`{ round_index }`) |
| DELETE | `/api/company-prep/:slug/progress` | Reset progress for a company |
| GET | `/api/company-prep/:slug/rounds/:index/attempts` | Get attempt history |
| POST | `/api/company-prep/:slug/rounds/:index/attempts` | Record a new attempt |
| POST | `/api/company-prep/practice/sessions` | Start a practice session |
| POST | `/api/company-prep/practice/sessions/:id/responses` | Submit a practice answer |
| POST | `/api/company-prep/practice/sessions/:id/end` | End a practice session |
| POST | `/api/company-prep/admin/seed` | Admin-only: upsert company_rounds from payload |

## Data Model

```
company_rounds
├── id, company_name, company_slug, company_color
├── company_tier, company_tagline, company_hiring
├── round_index, title, summary, duration_minutes, topics[]
└── test_paper_id (optional link to test_papers)

company_round_progress
├── student_id, company_slug, round_index
└── status (locked/unlocked/completed), completed_at

company_round_attempts
├── student_id, company_round_id, test_paper_id
├── attempt_number, started_at, submitted_at
├── obtained_marks, total_marks, percentage
└── status (in_progress/submitted/evaluated)

practice_sessions
├── student_id, company_name, category, topic
├── questions_answered, correct_answers
├── session_minutes, started_at, ended_at
└── company_round_id (optional)

practice_responses
├── session_id, question_id
├── selected_option, is_correct, answered_at
```
